Project Source code

Each **controller** handles incoming HTTP requests and passes data to the corresponding **Razor view**, which renders the final HTML response.  
Views are organized into folders named after their controller for a clean and consistent layout.

---

# 🎯 Project Overview

This project is built using **.NET 6** and follows the **Model-View-Controller (MVC)** architectural pattern.  
It is written in **Razor syntax** and organized into **controllers** and **separate view components** to maintain clean separation between business logic, routing, and presentation.

---

## 🧩 Technology Stack

- **Framework:** .NET 6  
- **Language:** C#  
- **UI Layer:** Razor Views (CSHTML)  
- **Architecture:** MVC (Model–View–Controller)  
- **IDE:** Visual Studio 2022 / VS Code  
- **Build System:** .NET CLI
